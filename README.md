# PumasProductManager

Julia package for managing Pumas product installations and versions.

## Installation and Usage

**Please see the [official documentation](https://docs.pumas.ai/stable/platformdetails/desktop/)
for details.**

## Support

Support requests should be sent to **support@pumas.ai** rather than this GitHub
repository. Please mention that you are using PumasProductManager.jl when
contacting support.
